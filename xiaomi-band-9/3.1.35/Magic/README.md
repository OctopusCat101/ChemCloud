# Magic

Chem 原生资源包管理模块，版本 **0.2.5 / code 7**，支持 **小米手环 9 / 固件 3.1.35**。

需要 Chem **0x26111309 或更新的兼容构建**，以及支持 Magic 导入的 ChemClient。

## 安装

在 ChemClient 连接手环、刷新云端列表，点击 Magic 安装。也可下载 [Magic 模块](Magic-Band9-3.1.35.chem)，直接在客户端导入。

更新后重启手环并运行 Chem，以释放旧模块回调；不必清空资源包。手环端列表点击资源包进入详情，使用紫色开关启用或关闭，下方可确认删除。已导入资源包可离线管理。

## 资源包下载

- [ABMF](ABMF-Band9-3.1.35.magic)：36 张应用图标、日历适配，仅应用列表与下拉通知菜单使用静态毛玻璃，其他区域保留系统背景。启用后先返回表盘采样。
- [VioletCalendar](VioletCalendar.magic)：最小日历示例。

下载 `.magic` 后，在 ChemClient 点击 Magic → 导入资源包。资源包不会自动启用，不经过表盘安装流程。文件长度与 SHA-256 见 [resources.json](resources.json)。

一次启用一个资源包；关闭恢复系统资源。删除当前资源包时先关闭，失败保留资源包；文件在下次重启后清理，以保护原生字体和图片引用。
